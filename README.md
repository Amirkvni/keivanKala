# Keivankala

A modern e-commerce web app built with Next.js, Tailwind CSS and MongoDB.

## 🚀 Features

- 🔐 JWT Authentication (Access & Refresh Tokens)
- 🛒 Shopping Cart and Wishlist
- 📱 Fully responsive (Mobile-First)
- 🌗 Light / Dark Theme Toggle
- 🔍 Product Filtering & Search
- 📦 REST API with MongoDB and Mongoose
- 📱 Login with Iranian phone number and SMS verification

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS
- **Backend:** MongoDB, Mongoose, Node.js API Routes
- **Auth:** Access & Refresh Token (JWT)
- **State Management:** Context API / Zustand
- **UI Enhancements:** SweetAlert2, React Icons
- **Deployment:** Vercel
